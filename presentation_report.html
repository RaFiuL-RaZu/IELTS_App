1. Executive Summary (প্রকল্পের সারসংক্ষেপ)

প্রেজেন্টেশন ওপেনিং স্টেটমেন্ট: "Sir, this application is a comprehensive, local-first IELTS preparation and real-time candidate analytics mobile solution designed to provide end-to-end practice across all 4 IELTS skill modules (Listening, Reading, Writing, Speaking) with Cambridge-standard automated band score estimation and dynamic performance tracking."

2. System Architecture & Technology Stack

📱 Frontend & UI Layer

Built with Flutter SDK and flutter_screenutil ensuring pixel-perfect responsive layouts across any screen density with custom Material 3 teal-slate design language.

⚡ State Management & DI

Powered by GetX for reactive state updates (.obs, Obx) and clean decoupled Dependency Injection (Get.put, Get.find).

💾 Persistence & Offline Engine

Engineered with a local-first caching architecture via SharedPreferences preserving user test history, band trends, and candidate goals without network dependencies.

🎙️ Audio Processing & Streams

Integrated with just_audio, audio_waveforms, and waveform_flutter enabling live audio streaming, microphone recording, and interactive visual waveforms.

5. Analytics & Scoring Engine Deep Dive (ডাইনামিক স্কোরিং লজিক)

The app's performance tracking (Skill-by-Skill Performance) is completely dynamic and recalculates across all modules in real-time:

🎧 Listening

Tracks score accuracy against total questions and estimates Band (0 - 9.0).

📖 Reading

Calculates passage score percentages and logs historical attempts.

✍️ Writing

Monitors submission counts, word length compliance, and rubric bands.

🗣️ Speaking

Logs cue card practice consistency and estimated fluency metrics.

📐 Official Cambridge Band Score Rounding Formula:

Average = (Listening + Reading + Writing + Speaking) / 4.0
• If fractional remainder < 0.25 ➔ Rounded down to nearest whole band.
• If fractional remainder ≥ 0.25 and < 0.75 ➔ Rounded to half band (.5).
• If fractional remainder ≥ 0.75 ➔ Rounded up to next whole band.
